# 音视频多媒体项目集

本仓库包含多个音视频处理方向的独立项目，每个项目位于独立子目录中。

## 项目列表

| 目录 | 项目名称 | 领域 |
|------|---------|------|
| `video-qc-service/` | 视频质检服务 | 音视频处理 |
| `audio-loudness-service/` | 批量音频响度处理服务 | 音视频处理 |
| `hls-fmp4-packager/` | fMP4 HLS 打包器 | 音视频处理 |
| `abr-ladder-generator/` | ABR 阶梯生成器 | 音视频处理 |
| `vfr-transcoder/` | VFR 转码器 | 音视频处理 |

## 领域
