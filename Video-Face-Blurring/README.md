# Video-Face-Blurring

视频人脸 / 隐私区域马赛克工具。零三方依赖（仅 Python 标准库 +
ffmpeg/ffprobe），打码、区域管理、编码三模块解耦。

## 用法

```bash
python blur.py 输入视频 输出视频 --region X,Y,W,H [--region ...] [--block 16]
```

- `--region` 可重复，像素坐标；`W/H` 为负时视为终点坐标写法
  （`(30,30,-8,-8)` ≡ `(22,22,8,8)`）；越界自动钳制，完全越界 /
  零面积丢弃。
- `--block` 全局网格块边长（像素），默认 16；`1` 为恒等基线。
- 退出码：0 成功；2 参数错误；5 探测失败；6 处理失败。

## 架构

```
vblur/
├── mosaic.py    打码：全局块网格上的一次性马赛克（BlockTable 契约）
├── regions.py   区域管理：钳制、线程安全运行时增删、代际缓存块表源
└── pipeline.py  编码：ffmpeg 解码 → 逐帧消费块表 → ffmpeg 编码
```

三模块之间的唯一数据契约是 `BlockTable`（全局网格参数 + 命中块清单，
不可变）。编码模块只消费 `frame_index -> BlockTable` 可调用对象，
不理解区域语义——后续自动检测（人脸 / 隐私区域识别）实现同一契约
即可接入：

```python
from vblur import RegionManager, blur_video

manager = RegionManager(1920, 1080)          # 尺寸须与视频一致
blur_video("in.mp4", "out.mp4",
           source=manager.as_source(16))     # 处理循环在后台跑
manager.add(100, 100, 200, 200)              # 任意线程随时增删
manager.remove(rid)                          # 已稳定帧不受影响
```

## 设计要点

1. **重叠只打一次、无拼接缝**：所有区域共用原点 (0,0)、边长固定的
   全局块网格；区域各自映射为命中块后求并集（set 去重），每块只对
   原图取一次均值、回填一次。重叠区不存在二次打码，也不存在两套
   网格相位错开的拼接缝。
2. **运行时增删不闪烁**：块均值只取决于块自身像素与全局网格相位，
   与其他区域无关。增删只改变命中块集合，既有块的网格相位与均值
   口径不变；块表源按代际缓存，无增删时逐帧返回同一不可变对象。
3. **钳制顺序固定**：负尺寸归一化 → 零面积丢弃 → 完全越界丢弃 →
   部分越界裁剪。`add` 对丢弃区域返回 `None`，不占 id。
4. **打码语义**：与区域有任意像素相交的网格块即命中，**整块**以
   逐通道均值回填（区域边缘向外取整到块边界，宁可多糊）。均值
   舍入 `(sum + n//2) // n`，定点可复现。`block=1` 退化为恒等。

## 输出一致性

- 帧率：`-framerate` 原样透传 ffprobe 的 `avg_frame_rate`；
- 帧数 / 时间戳：一帧入一帧出，不抽帧、不补帧、不改时间基；
- 尺寸：rawvideo 尺寸 = 探测尺寸；
- 像素格式：yuv420p/422/444 原样回写；RGB 输入走 libx264rgb
  （H.264 RGB 产物被 ffprobe 探为 `gbrp` 而非 `rgb24`，属 ffmpeg
  已知口径，`pix_fmt_matches` 视为等价）；gray 及其他非常见格式
  回退 yuv420p（libx264 只收 YUV 系）；
- 音轨：第二路 `-i` 原样 `-c:a copy` 直通。

工作格式固定 rgb24：打码在 RGB 空间对三通道整体求均值，避免只糊
亮度留下清晰色度的隐私泄漏。

## 已知取舍

- 纯 Python 打码循环（逐通道求和用步进切片加速），长视频吞吐受
  CPU 限制；内存恒定 O(单帧)。
- 子进程 stderr 一律 DEVNULL：置为 PIPE 而不消费会在长视频上撑满
  Windows 管道缓冲区（约 4KB）造成死锁；失败以退出码报告。
- 集成测试的有损编码断言用统计口径（块内动态范围塌缩、区域外
  平均差），swscale rgb→yuv420p 色度抽样抖动使逐字节比较不可行；
  打码精确性由 `test_mosaic.py` 的逐字节单测保证。
