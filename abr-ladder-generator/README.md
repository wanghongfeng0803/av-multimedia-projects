# ABR 阶梯生成器 (ABR Ladder Generator)

## 项目背景

带宽成本要降 30%，画质不能降。现有码率配置没有依据，全靠拍脑袋。需要做一个 ABR 阶梯生成器，用客观质量指标（VMAF/SSIM）来选档。

## 需求

### 输入输出

- **输入**：一个源片（1080p 或更高）
- **输出**：4 个档位的编码文件 + 质量报告

### 四档规格

| 档位 | 分辨率 | 标称码率 |
|------|--------|----------|
| 1080p | 1920x1080 | 5 Mbps |
| 720p | 1280x720 | 2.5 Mbps |
| 480p | 854x480 | 1 Mbps |
| 360p | 640x360 | 600 Kbps |

### 码率控制

- 各档**实测码率在标称值 ±3% 以内**
- **关键帧对齐**：所有档位的 GOP 结构一致，关键帧在同一时间点
- 切档不花屏：播放器在档位间切换时画面连续，无马赛克或撕裂

### 质量评估

- 用 **VMAF** 或 **SSIM** 做客观质量评分
- 给出每档的：
  - 平均 VMAF/SSIM 分数
  - 最低分场景（哪一段质量最差）
  - 选档依据（为什么这个分辨率配这个码率）
- 给出**相邻档位的质量差**（1080p vs 720p 差多少分，肉眼能否分辨）

### 性能要求

- 10 分钟素材
- 8 核机器
- **整条阶梯（4 档全部编码 + 质量评估）25 分钟内跑完**

## 技术约束

- 编码器使用 x264 或 x265（或 libaom/ SVT 系列均可）
- 可以用 ffmpeg 做编码，质量评估自己调库
- VMAF 计算可以用 `ffmpeg -filter_complex libvmaf` 或 `vmaf` Python 包

## 交付要求

- 命令行工具：`abr-ladder input.mp4 output_dir/ [--preset fast] [--vmaf-model vmaf_v0.6.1.json]`
- 输出目录包含：4 个编码后的视频文件 + `report.json`（每档码率、VMAF/SSIM 分数、关键帧对齐校验结果）
- README 说明：码率控制策略、关键帧对齐实现方式、质量评估方法论、性能优化手段
- 附带一个校验脚本，检查码率偏差和关键帧对齐
